Table S10 (selected 1016 version)
Run bash code/06/run_table_s10.sh after setting TABLE_S10_INPUTS and
DIA_NN_ANALYSIS_DIR. Optional TABLE_S10_OUT_DIR controls the output directory.
TABLE_S10_INPUTS contains double_edit_codons.tsv, theoretical_MS_candidates.tsv,
and double_edit_scores.cohort_mean.tsv generated by the upstream workflow.
DIA_NN_ANALYSIS_DIR contains AG_AS_WBG_iso1, dsim, dsec and dere tables named
<stem>_site_level_intensity_100AA.v2.tsv. These intermediate data are not bundled.
Dmel selects ISO1 and WBg, female and male replicates. Any edited MS support
means IA, AI or II; doubly edited support requires target-codon II.
Reference results: any edited 2/3/3/2; II 1/1/1/0 for Dmel/Dsim/Dsec/Dere.

The canonical candidate filename is theoretical_MS_candidates.tsv. It is
byte-identical to the historical Table_S11_theoretical_MS_candidates.tsv
(158 rows; SHA-256 c0d54be7d749998185596fc7986b20575c89390fb41fb2051df2ecdc5be3d5df).
Generate it without running historical MS/count summaries:
  python3 code/06/table_s10_multiedit/upstream/build_theoretical_ms_candidates.py \
    --pipeline-root /path/to/02_double_edit_and_MS \
    --projection-root /path/to/full_with_longest_projection_tables \
    --outdir "$TABLE_S10_INPUTS" --candidates-only
Also place 01_counts/double_edit_codons.tsv and
02_normalized/double_edit_scores.cohort_mean.tsv in TABLE_S10_INPUTS before
running bash code/06/run_table_s10.sh (also documented in section 08 of
06_MS_analysis.sh). The numbered main recipe does not accept stage arguments.
